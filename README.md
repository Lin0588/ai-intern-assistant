# AI 实习信息助手

基于 Dify 搭建的 RAG 知识库问答应用，帮助大学生用自然语言查询 AI 相关实习信息。

## 解决什么问题

- 实习信息散落在 Boss、实习僧、牛客，筛选耗时
- 岗位命名不统一，容易漏看
- 想按条件查（如“哪些要求 Python”“哪些一周4天以上”）需要逐个点开 JD

## 功能

- 自然语言查询实习岗位
- 混合检索（向量 + BM25），支持关键词精确匹配
- 回答附引用来源，降低幻觉
- 超纲问题拒答

## 技术栈

- 平台：Dify
- 模型：DeepSeek
- 检索：混合检索 + Rerank
- 索引：高质量模式，分段长度 800，重叠 100
- 知识库：12 条 AI 相关实习 JD(1条重复)



## 评测与迭代

设计 25 条评测集（常规/关键词/超纲），记录 Badcase 并迭代。典型问题：

| 问题 | 归因 | 优化动作 | 结果 |
|---|---|---|---|
| 问“哪些岗位提到 Python”答“无” | 向量检索不做关键词精确匹配 | 切混合检索 + 强制重新索引 | 正确列出 |
| 索引切高质量后检索失效 | 向量化未重新完成 | 禁用→启用，强制重新索引 | 恢复 |
| 小写 `ai` 匹配不到 `AI` | BM25 大小写敏感 | 文档统一大小写 + Prompt 加规则 | 改善 |

完整评测记录见 [eval/评测记录.md](eval/评测记录.md)。

## 已知限制

- TopK=10 上限，知识库 12 条，部分查询漏 1 条
- 同义词召回不稳定（如“编程”匹配不到“vibe coding”）
